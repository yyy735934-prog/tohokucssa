# 任务：生活指南内容 — 填充与完善

## 你的角色

你负责 `src/views/LocalGuide.vue` 的**内容建设**，把各板块的实用信息补充完整。
这是一个内容为主的任务，不需要写后端，主要是收集信息、整理成结构化数据，填入 Vue 组件中。

## 你只需要改这一个文件

```
src/views/LocalGuide.vue
```

## 当前状态

文件里已经有 5 个板块的骨架和部分示例内容：

| 板块 | key | 当前状态 | 你要做的 |
|------|-----|----------|----------|
| 医疗指南 | `medical` | 3 条基础信息 | 补充具体医院地址、科室、预约方式、牙科推荐 |
| 租房与打工 | `housing` | 2 条基础信息 | 补充租房网站链接、保证会社推荐、打工常见岗位、面试日语 |
| 原付驾照 | `license` | 2 条基础信息 | 补充模拟题网站链接、驾照翻译流程、中国驾照换日本驾照 |
| VPN / 校园网络 | `vpn` | 2 条基础信息 | 补充 VPN 详细设置步骤（Windows/Mac/手机）、图书馆远程访问 |
| 美食地图 | `food` | 空 | **从零填充**：仙台中华料理、学校食堂、平价超市、做饭采购指南 |

## 数据结构

每个板块是 `sections` 数组里的一个对象，你只需要往 `items` 数组里添加条目：

```js
{
  title: '条目标题',
  content: '详细说明文字，一两段话即可',
  link: 'https://相关网站',        // 可选
  linkText: '链接显示文字'          // 可选，默认"了解更多"
}
```

## 示例：给美食地图加内容

找到 `sections` 数组里 `key: 'food'` 的对象，把 `items: []` 改成：

## 内容收集建议

- 医院信息：Google Maps 搜 "病院 仙台" 确认地址和电话
- 租房：SUUMO、HOME'S、学校国际交流课网站
- 驾照：宫城県警察 HP 的免許案内页面
- VPN：东北大学 TAINS 网站
- 美食：问问身边同学，或查食べログ（tabelog.com）

## 运行预览

```bash
npm install
npm run dev
```

打开 http://localhost:5180/local 就能看到你改的内容。

## 提交方式

改完后提交到这个分支，然后在 GitHub 上创建 Pull Request：

```bash
git add src/views/LocalGuide.vue
git commit -m "docs: 补充医疗指南详细信息"
git push
```

信息的准确性很重要——电话号码、地址、费用请务必核实。
